Mémento des commandes Linux

Ce mémento regroupe les principales commandes Linux vues en cours de SISR.

Commande Description Exemple d'utilisation
Navigation et fichiers
pwd Affiche le répertoire courant pwd
ls Liste les fichiers et dossiers ls -l
cd Change de répertoire cd /home/user
mkdir Crée un dossier mkdir projets
touch Crée un fichier vide touch notes.txt
cp Copie un fichier ou un dossier cp notes.txt copie.txt
mv Déplace ou renomme un fichier mv notes.txt /tmp/
rm Supprime un fichier (ou un dossier avec -r) rm notes.txt
Lecture et recherche
cat Affiche le contenu d'un fichier cat /etc/hostname
nano Édite un fichier dans le terminal nano fichier.txt
grep Recherche un mot dans un fichier grep "erreur" /var/log/syslog
find Recherche des fichiers find / -name "*.conf"
Droits et utilisateurs
chmod Modifie les droits d'un fichier chmod 755 script.sh
chown Change le propriétaire d'un fichier chown user fichier.txt
sudo Exécute une commande en administrateur sudo apt update
whoami Affiche l'utilisateur courant whoami
useradd Crée un utilisateur sudo useradd -m alice
Système et réseau
ps Liste les processus en cours ps aux
kill Arrête un processus grâce à son PID kill 1234
df Affiche l'espace disque df -h
ip a Affiche les adresses IP de la machine ip a
ping Teste la connexion avec une machine ping 8.8.8.8
ssh Se connecte à une machine à distance ssh user@192.168.1.10
apt install Installe un paquet sudo apt install apache2
man Affiche le manuel d'une commande man ls
